# regs-website

Marketing site with appointment booking that opens WhatsApp (Vite + React). No backend.

## Quick start

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |

## Customize

Edit [`src/data/salon.js`](src/data/salon.js) for phone, address, hours, services, and copy.

See [`CLIENT_DETAILS.md`](CLIENT_DETAILS.md) for the intake checklist.

## Deploy

Built for **Vercel** (static Vite app). Connect this GitHub repo in the Vercel dashboard — build command `npm run build`, output `dist`.
